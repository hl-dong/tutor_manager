# 家教课时管理工具 (Tutor Manager)

## 📖 项目背景
我在做家教（一对一及机构兼职）时，发现课时记录或查看非常繁琐。为了自己管理方便，同时作为转行编程的求职项目，我开发了这款命令行工具。

## ✨ 功能特性
- **学生管理**：添加、查看学生信息（年级、科目、联系方式等）。
- **课时记录**：记录每次课时（日期、时长、单价），自动计算金额。
- **筛选功能**：支持按学生、按月份筛选课时记录。
- **收入统计**：自动统计某月总课时、应收总额、已收金额和未收金额。
- **付款标记**：一键标记课时已付/未付。
- **数据持久化**：数据自动保存到本地 JSON 文件，重启不丢失。
- **导出 CSV**：一键导出课时记录为 CSV（已处理中文编码，Excel 打开不乱码）。

## 🛠️ 技术栈
- **语言**：Python 3.13
- **存储**：JSON（文件存储）
- **标准库**：json、csv 等
- **版本控制**：Git + GitHub

## 🚀 如何运行
1. 克隆本项目到本地。
2. 确保安装了 Python 3.10+ 环境。
3. 在项目根目录运行：
   python main.py
4. 按照控制台提示输入数字进行操作。
